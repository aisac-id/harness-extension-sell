# Brand & Promotion Kit — Harness Sell Kit

Identitas visual resmi paket jual Harness Extension. Kit ini punya identitas sendiri (teal–amber commerce) yang terpisah dari kit standar `harness-extension` (blueprint biru). White-label boleh mengganti sesuai bagian 9 STANDARDS.md.

## Aset

| File | Ukuran | Kegunaan |
|---|---|---|
| `logo.png` | 1024×1024 | Logo utama: price-tag dengan monogram "H" emboss + roket peluncuran dan percik amber |
| `icons/icon-16/32/48/128.png` | 16–128 px | Ikon manifest extension (salin HANYA ini ke package extension) |

| `social-square.png` | 1024×1024 | Postingan launch sosial media (IG/LinkedIn/X) |
| `promo-video.mp4` | 1920×1080, 8 dtk | Video promosi sinematik (landing page, iklan, intro video course) |

## Identitas

- **Konsep logo**: price-tag (label harga) dengan monogram "H" emboss dan roket kecil yang lepas landas — simbol menjual & meluncurkan produk. Percik api amber menjadi aksen khas.
- **Warna**: Deep Navy `#0B1220` (latar), Teal→Cyan `#14B8A6 → #22D3EE → #38BDF8` (permukaan utama), Amber `#F59E0B` (aksen komersial/foil), Putih `#F8FAFC` (teks), abu tipis untuk sekunder.
- **Tipografi**: sans-serif tebal untuk judul, uppercase dengan letter-spacing lebar untuk label; hindari font dekoratif.
- **Tagline**: EN "Landing. Brand. Playbook." — ID "Paket jual lengkap: landing page, brand kit, playbook."
- **Gaya**: gelap, glow teal hangat dengan sentuhan amber, flat-lay isi kit, tanpa gradien ramai — premium, bukan norak.

## Aturan pakai

1. Jangan mengubah bentuk/warna logo; jangan menambah efek ke logo.
2. Aset `brand/` adalah materi MARKETING — **jangan dimasukkan ke package extension** (aturan bundle < 500 KB, STANDARDS.md bagian 2). Yang disalin ke extension hanya `icons/`.
3. Untuk bundling (buku/video), gunakan `software-box.png` di sampul/halaman bonus dan `poster.png` untuk materi cetak.
4. Video boleh dipotong/di-loop, tapi jangan mengubah teks di dalamnya.
